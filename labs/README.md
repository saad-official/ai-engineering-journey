# Labs

Small, focused exercises. One folder per lab, numbered in roadmap order: `labs/01-hello-llm`, `labs/02-tokens`, ...

Each lab folder contains:
- `pyproject.toml` + `.python-version` (own `uv` environment; fast to create, cheap to delete)
- `main.py` (or a few modules)
- `NOTES.md`: what was tried, numbers observed, what was learned, the open question
- `.env.example` if it needs keys

Labs are allowed to be messy. The learning goes into `NOTES.md`, then into `EXPERIMENTS.md` (one row) and `notes/concepts/` (the durable write-up).

Index of planned labs is in `AI_ENGINEERING_ROADMAP.md` under each phase's "Hands-on exercises".
